A movement, not a syllabus

Built on seven
quiet promises.

STJR isn't a class. It's a recurring studio where second and third-year students lead ninety-minute workshops for first-years on the things nobody taught them — code, money, words, time, careers. The trick is that the seniors learn twice as much.

01 · Promise↗
1

Real teaching, not slides.

Each session has one host, one project, ninety minutes, and zero theory. You build something real with the person next to you. If it doesn't ship by the end, it doesn't ship at all.

1 host · 1 project90 min

The shape of the evening

One Tuesday,
one Friday. Every week.

Each evening is a single-topic studio — one host, one project, ninety minutes of build-and-ship. The session repeats the following evening for the people who couldn't make it. Same content, different crowd.

5:00 — 5:15↳ Arrive

Doors, chalk, chairs.

Walk in. Find a seat. Get the worksheet. The host is at the board, drawing the thing you'll build tonight.

5:15 — 6:00↳ Build

Forty-five minutes of build.

Code, write, design, calculate — whatever the topic demands. The host moves through the room. First-years pair up.

6:00 — 6:20↳ Demo

Show & tell.

Three volunteers demo what they built. Applause. The host does it the boring, correct way.

6:20 — 6:30↳ Close

Q & A.

Anything that's still unclear. The host stays back for as long as you stay back.

After↳ Host dinner

Canteen, free.

The host and the volunteers get dinner on the workshop. Anyone who wants to keep talking is welcome.
